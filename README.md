### 👨‍💻 Perfil Ejecutivo & Filosofía de Desarrollo

Desarrollador Front-End Jr. enfocado en la construcción de **software de alto rendimiento**, escalable y centrado en el usuario. Apasionado por la arquitectura de código semántico, la manipulacion directa y eficiente del DOM, el consumo de datos estructurados (JSON/APIs) y el diseño adaptable (Responsive Web Design).

* 📍 **Ubicación:** Bucaramanga, Santander, Colombia.
* 🎯 **Enfoque Técnico:** Aplicación de principios **Clean Code**, accesibilidad web (**A11y**), semántica HTML5 estricta y preparación constante para el ecosistema moderno de JavaScript (React/Frameworks).
* ⚙️ **Workflow:** Control de versiones avanzado con **Git/GitHub**, estructuración modular de estilos y diseño de diagramas relacionales en **MySQL**.
